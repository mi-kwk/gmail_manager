# Gmail Manager

Windows 11向けの複数Gmail整理アプリです。仕様の正本はNotionの「Gmail整理ツール」です。
https://app.notion.com/p/3fa232d7afe481c1b92afb5f5639bbfd

## 起動

配布フォルダー内の GmailManager.exe を起動してください。
win-x64の自己完結版には.NETランタイムが含まれます。フォルダー全体を同じ場所に置いてください。

ソースから起動する場合は.NET 10 SDKが必要です。

    dotnet run --project src/GmailManager

## 最初のGoogle連携

1. Google Cloudで利用するプロジェクトのGmail APIを有効にします。
2. Google Auth Platformで同意画面を設定し、テスト運用なら利用するGmailアカウントをテストユーザーに登録します。
3. OAuthクライアントの種類を「デスクトップアプリ」として作成し、クライアントJSONをダウンロードします。
4. アプリの「Gmailを追加」を押して、そのJSONを選択します。
5. ブラウザーで対象のGoogleアカウントを選び、Gmail連携を許可します。
6. 必要なアカウントごとに追加操作を繰り返し、「全アカウントを同期」を押します。

認証はGoogle公式.NETクライアントのブラウザー／ローカルリダイレクト方式を使います。
要求スコープは gmail.modify です。パスワードをアプリへ入力する必要はありません。
Google設定やテストユーザーの状態により、再認証が必要になる場合があります。
JSONを入れ替える場合はアプリを終了して保存フォルダー内の client_secret.json を差し替え、各アカウントを再追加してください。

公式資料:
- https://developers.google.com/identity/protocols/oauth2/native-app
- https://developers.google.com/workspace/gmail/api/guides/list-messages
- https://developers.google.com/workspace/gmail/api/reference/rest

## 使い方

- 統合メール: 全アカウント／アカウント別で表示。送信元で絞り込み、チェック欄で複数選択できます。件名・送信元・アカウント名による検索、本文プレビュー、重要登録、ゴミ箱移動、アーカイブ、ラベル分類に対応します。
- 送信元分析: メールアドレス完全一致で集計し、全体件数とアカウント別内訳を表示します。送信元指定の全件操作では全アカウントを再同期してから対象を確定し、確認画面を表示します。
- 重要メール保管庫: 元アカウント・送信元・件名による検索／絞り込み。各検索欄は大文字小文字を区別しない部分一致、複数欄はANDです。保存済み本文はアプリ内で表示し、添付は保存できます。
- バックアップ管理: 重要解除済みも含めて状態と保存先を確認し、閲覧・保存再試行ができます。
- アカウント: 選択したアカウントにアプリ内表示名を設定します。同名可。Googleプロフィールは変更しません。
- 結果・履歴: メール単位の成功・失敗・保護除外・未処理を確認し、失敗対象だけを再試行できます。

## 削除と保護の仕様

- 削除はGmailのゴミ箱移動です。完全削除は実装していません。
- 全期間、既読未読、受信トレイとアーカイブ済みを対象とし、迷惑メール・ゴミ箱を除外します。送信元はメールアドレス完全一致です。ドメイン単位は未実装です。
- 全件の対象は確認前の同期完了時に固定します。同期後に届いたメールはその操作には追加しません。
- 50件ごとの区切りで対象を分け、メール単位で順に送信します。進捗と結果を表示します。
- キャンセルは未送信の処理を止めます。既に送信したリクエストは完了を待ち、処理済み分を自動復元しません。
- 各削除リクエスト直前に保護を再確認します。重要登録では選択した全件の保護を先にSQLiteへ保存し、その後にバックアップします。
- バックアップ待ち・実行中・失敗中も保護を維持します。重要解除しても保存済み実体は残ります。
- アプリが異常終了した場合、保存中は失敗として再試行可能にし、送信中の操作は「要確認」とします。「要確認」は自動再試行しません。
- 削除保護の対象はこのアプリからの削除です。Googleや別クライアントの操作を遮断するものではありません。

## ローカル保存

保存先は %LOCALAPPDATA%\GmailManager です。「保存フォルダー」で開けます。
- gmail.db: アカウント、表示名、メール索引、保護状態、バックアップ索引、履歴（SQLite）
- tokens: Googleトークン。Windows DPAPIの現在のユーザーで暗号化
- backups: 本文・添付を含む元メール形式（EML）
- client_secret.json: 利用者が選択したデスクトップOAuthクライアント設定

保存済みEMLはGmailへアクセスせずに読むため、オフラインやGmail側の元メール削除後にも閲覧できます。
HTML本文は文字として表示し、外部画像・スクリプトを実行しません。
EMLと索引の暗号化は今回の初期実装には含まれません。保存先変更、移行UI、保持期間、自動バックアップ削除、復元・エクスポートUIは未実装です。
EMLを含む保存フォルダーは利用者側で保持してください。Googleトークンの別Windowsユーザーへのコピーでは復号できません。

## 実装上の選択と未検証範囲

C# / .NET 10 / WPF、Gmail公式.NETクライアント、SQLite、MimeKitで初期実装しました。
これは今回の実装上の選択であり、Notionの未決事項全体を確定したという意味ではありません。
WPF画面と処理・保存のCoreを分けています。MVVM専用フレームワークは未採用です。
ラベルのアカウント間対応が未決のため、ラベル分類は1アカウントずつ、既存のユーザーラベルを選ぶ方式です。
初回同期は全メールのメタデータを順に取得します。大量メールでの所要時間・性能目標は未検証です。
実GmailのOAuth接続、メール変更、添付取得は利用者のOAuth設定が必要なため未検証です。
配布署名、インストーラー、自動更新、一般公開向けOAuth審査は今回の範囲に含みません。

    dotnet build GmailManager.slnx

## 画面改善（送信元絞り込み・本文プレビュー）

統合メールは左に送信元一覧、中央にメール一覧、右に本文を配置しました。
1. 左の送信元をクリックすると、そのメールアドレスと完全一致するメールだけが表示されます。
2. 中央の行をクリックすると、右側に本文を表示します。重要登録していないメールもGmailから取得して読めます。保存済みメールはローカルのバックアップを優先します。
3. 削除するメールのチェック欄をオンにし、「チェックしたメールを削除」を押して確認します。「表示中をすべてチェック」で、絞り込み結果だけを選択できます。
4. 本文の「別ウィンドウで開く」から大きな画面でも読めます。添付は保存できます。
5. アカウントは表示名を基本とし、元のメールアドレスを統合一覧・保管庫・送信元分析から非表示にしました。同名には番号を付けます。元アドレスの確認は「アカウント」画面でできます。

フィルターを変更した際はチェックを解除します。削除対象はチェックしたメールだけで、本文を読んだだけでは選択されません。
本文はテキストとして表示し、外部画像・スクリプトは実行しません。未保存メールの本文取得にはオンライン接続が必要です。
追加検証：通常メールの本文解析、HTML本文のテキスト表示。Core検証は合計17項目。
